## Addressed reviewer findings

- `M4-UX-R01`: built-in and constructed source imports no longer enter the
  legacy file validator. File validation is activated only by an explicit file
  choice, and stale file-only notifications are cleared for non-file imports.
  Three fresh English sessions and one German session showed no false
  structural error during the successful D65 handoff.
- `M4-UX-R02`: both import actions name Transmission as their destination.
  Successful source activation opens Transmission and synchronizes the active
  sidebar item. The Import page states that a source unlocks Transmission.
- `M4-UX-R03`: a confirmed source activation resets the wizard to Spectrum,
  rather than leaving the user on a disabled Promote step.
- `M4-UX-R04`: cancelling or dismissing a guarded source import does not consume
  the request. Repeating the same-source import reopens confirmation, while
  preserving state until confirmation.
- `M4-UX-R05`: a parseable transmission upload may continue to Measurement when
  its current fraction/percent interpretation is invalid. A visible
  semicolon-delimited, comma-decimal percentage upload reached Measurement,
  exposed the scale control, and recovered to Percent by keyboard.
- `M4-UX-R06`: selected catalogue cards show source version or pinned revision
  before Apply. Expandable measurement and processing details show geometry,
  thickness, transmittance type, source point count, and transformations.
- `M4-UX-R07`: the persistent preview uses compact actionable feedback when no
  parseable curve exists. It does not reserve an empty plot. Parseable partial
  curves continue to render.
- `M4-UX-R08`: Import and wizard containers constrain component width and page
  overflow. Tables retain local overflow, and wizard labels have additional
  separation from their radio controls.
- `M4-UX-R09`: German visible and accessible Transmission copy covers workflow
  controls, readiness, plots, tables, statuses, downloads, archive UI, and
  undefined values. Scientific symbols and units remain unchanged.

## Additional provenance correction

The browser provenance check exposed that `photobiologyFilters` stores glass
thickness in metres. Catalogue preparation now converts that field to
millimetres. The bundled IPLUS record displays `4 mm`, and its processing note
explicitly documents the conversion. A deterministic test protects the value
and transformation statement.

## Intentional limitations

- History lasts for the current Shiny session only.
- Solar transmittance, g-value, angle-dependent optics, fluorescence modelling,
  and new colour metrics remain outside this module's scope.
- Measurement angle is audit metadata and does not alter calculations.
- Literal forward and reverse Tab traversal requires one final manual sample
  because the in-app browser controller cannot synthesize it reliably.
