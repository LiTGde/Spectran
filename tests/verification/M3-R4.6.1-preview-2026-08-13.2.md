# Milestone 3 promotion and import-safeguard revision

Build: `M3-R4.6.1-preview-2026-08-13.2`

Review URL: <http://127.0.0.1:43835/>

Date: 2026-08-13

## Findings addressed

- `M3-UX-R01`: Promotion names now commit when the field loses focus, before
  mouse or keyboard activation reaches the promotion action. The value visibly
  present at activation is trimmed, validated, and used for the history node,
  activation event, status, CSV history, and audit ZIP.
- `M3-UX-R02`: Replacing a history with promoted work now opens an explicit
  confirmation. It freezes and names the requested source, states how many
  promoted nodes and all branches will be removed, and provides Cancel and
  Import and clear history actions. Cancel and Escape preserve the active
  source, history, draft, and provisional result. Root-only history still
  resets directly.

## Intended review journeys

- Apply the default Selective filter, replace the generated promotion name,
  and immediately promote by mouse, Enter, and Space without waiting.
- Repeat with whitespace around a custom name and verify that it is trimmed.
- Confirm that a blank or whitespace-only name remains blocked.
- Create sequential promoted nodes, restore the root, and create a sibling
  branch. Verify the custom names in the history table and audit downloads.
- With promoted history present, request a same-source or different-source
  import. Cancel by button and Escape and verify that all visible state remains
  unchanged.
- Confirm the import by mouse, Enter, and Space. Verify exactly one import,
  one visible root, cleared provisional results, and disabled downloads.
- With root-only history, import another source and verify that it proceeds
  directly without an unnecessary confirmation.

## Development-only elements

- The source and filter fixture selectors, explicit source-import button,
  Development status, raw node/revision counters, and synthetic fixtures are
  part of the isolated showcase only.
- The confirmation controller and its destructive-reset contract are intended
  for production integration when a real source import would replace promoted
  session history.

- History is intentionally session-local.
