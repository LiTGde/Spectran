## Scope

This focused revision addresses the remaining `M4-UX-R31` title-subtitle
collision in a 320 CSS px German promoted archive with panel B. Scientific
calculations, result data, title text, right padding, plot layers, current
results, and PNG export behavior are unchanged.

## Change

- Narrow archived plots now measure the wrapped result title's actual line
  count.
- An archived title with four or more lines receives a 12-point bottom margin
  before the semantic subtitle.
- This `.26` implementation leaves three-line titles without an added gap;
  reviewer verification found that the English archive still collides in that
  state. The follow-up `.27` revision supersedes this behavior.
- Adaptive spacing is enabled only for archived in-app result plots. Current
  result plots and PNG exports retain the accepted layout.
