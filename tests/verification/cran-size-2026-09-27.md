# CRAN package size verification

The transmission/reflection extension meets the project's conservative
5,000,000-byte budget for the source archive and installed package.

CRAN's current policy asks that data and documentation normally remain below
5 MB each, while source archives should preferably remain below 10 MB.
The project's archive budget is deliberately stricter. Policy checked on
2026-09-27: https://cran.r-project.org/web/packages/policies.html.

## Repeatable release gate

Run after building/checking a candidate:

```sh
Rscript --vanilla data-raw/validate_package_size.R \
  /path/to/Spectran_1.0.6.tar.gz /path/to/Spectran.Rcheck/Spectran
```

The installed-package argument is optional. The checker audits the actual
source archive, verifies that excluded files did not ship, reports the
component sizes and archive checksum, and exits unsuccessfully if a size
budget is exceeded. Its `validate_` name keeps it out of the existing raw-data
regeneration driver's automatic sourcing.

The actual candidate passed. A temporary oversized archive containing a
6,000,000-byte synthetic data payload was correctly rejected with exit status
1. Negative test log: `/private/tmp/spectran-size-negative-check.log`.

The packaged B04 candidate also passed all 1,561 assertions and R CMD check with
zero errors, warnings or notes. Command:
`Rscript --vanilla /private/tmp/spectran-check.R`.
Log: `/private/tmp/spectran-ux-b04-check.log`.

The earlier B02 packaged build measured 3,148,932 bytes for the source archive
and 4,055,807 bytes installed, with 1,376 passing assertions. Its measurements
remain in `/private/tmp/spectran-size-budget.log`. B03 measured 3,149,588 bytes
