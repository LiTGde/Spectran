## Scope

This revision addresses only the user-directed visual and interaction
conformity findings `M4-UX-R25` through `M4-UX-R28`. The weighting functions,
efficacy constants, normalization rules, applied spectra, and metric
calculations are unchanged.

## Addressed findings

- `M4-UX-R25`: current and archived comparison figures now use the ordinary
  Analysis visual hierarchy. The source and filter name plus a semantic
  incident/transmitted subtitle are inside the figure. The plot canvas,
  typography, margins, axis treatment, and A/B spacing follow the Analysis
  presentation. The transmittance panel remains narrower on desktop and stacks
  below panel A on narrow screens. In-app plots and PNG exports use the same
  rendering function.
- `M4-UX-R26`: Results exposes Melanopsin, L-cone-opsin, M-cone-opsin,
  S-cone-opsin, Rhodopsin, and photopic V(lambda) as six independent choices.
  The controls form a compact Analysis-style group above the figure. The
  Transmission-specific incident-fill and panel-B choices remain separate.
  Every selected curve is carried into the current and archived plot exports.
- `M4-UX-R27`: the Results plot, metric navigation, and all three gt tables now
  form one continuous Analysis-style package. Current and archived tables use
  the app font, transparent Analysis canvas, restrained rules, lighter headers,
  compact row rhythm, and attached notes. The three metric groups and local
  table overflow remain available.
- `M4-UX-R28`: Transmission Export now follows the ordinary Export hierarchy.
  It provides plot width, height, font size, and optional irradiance maximum;
  carries the active Results plot choices; adds plot-plus-table PNG output;
  supports configurable bundle contents with a live file count; and makes the
  selected ZIP bundle the full-width yellow primary action. Individual files
  remain available as secondary quick downloads in collapsed figure, table,
  and data groups.

## Intentional differences from ordinary Analysis

- Panel B stacks below panel A at narrow widths. This preserves the accepted
  responsive Transmission behavior instead of copying the current CRI panel
  overlap in Analysis.
- Incident fill and the transmittance panel are Transmission-specific plot
  options and remain separate from the six shared action-spectrum controls.
- Three metric tabs remain because the Transmission result has three distinct
  table families. Their presentation now follows the Analysis package style.
- Quick individual downloads remain available, but they are secondary to the
  configurable bundle action.
