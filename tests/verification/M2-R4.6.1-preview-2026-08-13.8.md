## User-directed changes

- Replaced the Filter name, Transmission scale, Transmittance type, and
  Measurement angle fold-outs with compact information icons beside their
  field labels.
- Added information icons for Transmission CSV, Scattering or diffusing
  sample, and Measurement geometry.
- Combined the transmittance-type definitions and passive, non-fluorescent
  model limitation in the Transmittance type tooltip.
- Retained Flexible CSV settings as a disclosure because it contains input
  controls. Retained Technical denominator details as a disclosure because it
  contains longer audit information.
- Every tooltip uses the accepted `.7` pointer, focus, click, Escape-dismiss,
  and re-arm interaction. Each trigger is a native button with an accessible
  name and `aria-describedby`; each content element has `role="tooltip"`.
- Tooltip content is positioned from the complete field-label row. This keeps
  all seven tooltip panels within the narrow form column and removes clipping
  for long labels such as Measurement geometry.

No normalization rule, readiness gate, Apply behavior, scientific
calculation, metric definition, applied snapshot, or export contract changed.
