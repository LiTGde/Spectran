## Intended review journeys

- Confirm that Transmission is locked to Import until a source spectrum is
  active, then opens as a dedicated page between Import and Analysis.
- Select a featured facade glazing, search all 26 facade/window spectra, and
  search the 121-filter Spitschan et al. collection. Inspect source, citation,
  licence, version, and measurement metadata without network access.
- Upload a transmission CSV and follow the five wizard steps: Spectrum,
  Measurement, Normalization, Apply, and Promote. The live normalization
  preview remains beside the active step and shows incomplete or invalid data.
- Exercise fraction/percent scaling, Total/Internal/Unknown type handling,
  missing-tail choices, large-gap acknowledgement, and scattering geometry.
- Apply the completed filter to the active source. Inspect D65-referenced
  filter properties, incident/transmitted absolute values, retained response,
  action-factor changes, DER changes, and explicit Undefined states.
- Promote with an immediately edited name. Verify that the applied result is
  archived and remains fully visible and downloadable after promotion.
- Apply another filter to the promoted source as an explicit sequential
  calculation. Restore an earlier node and create a sibling branch.
- Import a new source over promoted history. Cancel once, then confirm. Verify
  state preservation on Cancel and a one-root reset only after confirmation.
- Repeat representative journeys in English and German, with pointer and
  keyboard operation and responsive widths from 320 to 1440 px.

## User-directed changes included

- Focus outlines for edge controls are inset into padded component containers,
  preventing the active border from being clipped on the left or bottom edge.
- Promotion no longer removes the applied result. A complete immutable archive
  remains visible, with its plot, tables, warnings, metadata, and six downloads.
- A later Apply is labelled and treated as a separate sequential filtering
  calculation using the promoted spectrum as the new incident source.
- The production page uses a guided wizard with a persistent live preview.
- Compact accessible information tooltips replace short explanatory foldouts.
- Transmission plots and tables use Spectran's yellow, white, and dark styling.

## Development-only elements

- The visible build identifier is enabled only through the
  `Spectran.review_build_id` option used for review instances.
- Deterministic synthetic filter fixtures and raw revision diagnostics remain
  available to isolated module tests, not the integrated production page.

## Intentional limitations

- History lasts for the current Shiny session only.
- Solar transmittance, g-value, angle-dependent optics, fluorescence modelling,
  and new colour metrics remain outside this module's scope.
- Measurement angle is audit metadata and does not alter the completed curve.
- Literal Tab and Shift+Tab traversal should receive one final manual sample
  because the in-app browser controller cannot synthesize that traversal.
