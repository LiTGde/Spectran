# Milestone 3 promotion, history, and export review build

Build: `M3-R4.6.1-preview-2026-08-13.1`

Review URL: <http://127.0.0.1:43834/>

Date: 2026-08-13

## Intended review journeys

- Apply a ready filter, edit the generated `source × filter` name, and
  promote the transmitted spectrum as Spectran's active source.
- Apply the same or another filter to the promoted source and promote again.
- Restore an earlier history node without deleting descendants.
- Restore the root and promote a new result to create a visible alternative
  branch.
- Import another development source and confirm that the old tree is cleared
  and replaced by a new visible root.
- Confirm that an applied result becoming stale disables promotion and all six
  downloads until Apply is pressed again.
- Download completed filter, spectral comparison, D65 properties, applied
  metrics, and history CSVs plus the bilingual audit ZIP.

## Changed areas

- Added pure active-spectrum adapters and explicit promotion/restore event
  payloads.
- Added a session-local rooted history tree with promotion children, pointer
  restore, branch retention, and source-import reset.
- Added an editable promotion name, promotion action, restore selector, visible
  history table, and current-state feedback.
- Added quick CSV downloads and an audit ZIP containing input records, parsed
  and completed curves, status flags, spectra, metrics, the full history tree,
  every node spectrum, metadata, decisions, warnings, citations, licences, a
  manifest with MD5 checksums, and an English/German README.
- Exact uploaded bytes are frozen at Apply and preserved in the audit ZIP.
- The provisional snapshot is archived and reset after promotion or restore.
- Import, promotion, restore, and Apply support ordinary keyboard activation.

## Development-only elements

- The source and filter fixture selectors, explicit source-import button,
  Development status, raw node/revision counters, and synthetic fixtures are
  part of the isolated showcase only.
- In the integrated app, a real source import will create the root and the
  parent server will activate promotion and restore payloads.

## Known deferred limitations

- The integrated locked Transmission navigation page, import handoff, and
  existing Analysis/Export propagation remain Milestone 4 work.
- Both offline catalogues, source citations and licences, bilingual workbook
  integration, production wizard layout, Spectran-consistent plot/table
  styling, and full accessibility/browser integration remain Milestone 4.
- History is intentionally session-local.

## Recommended test data

- Development source fixtures: D65, equal-energy, and zero spectrum.
- Development filter fixtures: Selective, Neutral 50%, Large gap, Partial
  coverage, and Invalid.
- The generated 100% template or any prior quick completed-filter CSV can be
  uploaded to test exact input preservation in the audit ZIP.
- Real-world glazing, integrating-sphere, clinical/selective, and dense vendor
  examples remain scheduled with the offline catalogues in Milestone 4.
