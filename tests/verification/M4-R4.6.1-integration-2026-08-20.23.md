metric presentation, plot layers, export contents, and the accepted PNG
layout are unchanged.

## Change

- In-app result plots use an additional compact title-wrap tier for measured
  widths below 350 CSS px.
- Hyphenated source names gain optional wrap positions after their existing
  hyphens. The rendered title text remains unchanged when the lines are read
  together.
- Current, stale, frozen, and archived in-app results share the same responsive
  title helper.
- PNG export continues to use the established export title width, which
  already displayed the complete title correctly.
