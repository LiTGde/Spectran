## User-directed changes

- Transmission is an optional spectrum-dependent page after Export in the
  sidebar. Import opens Analysis and only unlocks Transmission.
- The five-step wizard was replaced by Analysis-style tabs for Spectrum,
  Measurement, Normalization, Results, and History and downloads.
- Every input tab retains its own live normalization preview beside the active
  controls. The compact preview is 340 px high. Parsed rows, construction
  details, status counts, and the preview PNG download are inside an optional
  disclosure below the plot.
- Applied results now have a dedicated Results tab. A promoted result remains
  fully visible there as a frozen result rather than disappearing.
- Preview, applied-result, archived-result, and session-history tables now use
  `gt` with Spectran-aligned hierarchy, spacing, striping, active-state
  emphasis, semantic labels, and local responsive overflow.
- Applied spectral plots use Spectran's spectral palette, a zero baseline,
  clearer incident/transmitted distinctions, and Analysis-aligned typography.
- Plot options can add transmittance as a narrower panel B to the right of the
  incident/transmitted spectrum.
- PNG downloads are available for the normalization transmittance plot and for
  current or archived result plots. Result PNG downloads respect the panel B
  option.

All scientific calculations, normalization rules, catalogue provenance,
history semantics, CSV exports, and audit ZIP contracts remain unchanged.

## Intentional limitations

- History remains session-local.
- Solar transmittance, g-value, angle-dependent optics, fluorescence modelling,
  and new colour metrics remain outside scope.
- Measurement angle remains audit metadata only.
- Literal full Tab and Shift+Tab traversal remains a manual review item because
  the in-app browser controller cannot synthesize it reliably.
