## Scope

This focused revision addresses the remaining `M4-UX-R31` archived-result
case only. Scientific calculations, metric presentation, plot layers, export
contents, and the accepted PNG layout are unchanged.

## Change

- The archived result renderer now derives title wrapping from its own output
  width rather than only the page-level plot width.
- For an actual archived plot width below 260 CSS px, long unbroken title
  components gain a conservative internal line-break opportunity. The exact
  title remains unchanged when its lines are read together.
- Current, stale, and frozen result-title behavior remains unchanged.
- PNG export continues to use the established export title layout, which was
  already accepted.
