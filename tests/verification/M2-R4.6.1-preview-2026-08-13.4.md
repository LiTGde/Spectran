## User-directed changes

- New filters start with Fraction and Total transmittance selected. These safe
  defaults are restored when the filter source changes.
- The passive, non-fluorescent statement remains unchecked. It is a factual
  attestation, so Apply remains unavailable until the user confirms it.
- Longer field explanations moved into compact, initially collapsed native
  `details` disclosures. The passive-filter disclosure explains that a
  fluorescent material can absorb light and re-emit it at different
  wavelengths, which wavelength-by-wavelength multiplication cannot model.
- The construction plot is fixed to the physical transmittance range 0 to 1
  with no padding below zero.
- The incident/transmitted irradiance plot starts exactly at zero. A zero-only
  spectrum receives a small positive upper range so the coincident lines and
  zero baseline remain visible.

The current application uses Bootstrap 3. Native HTML disclosures preserve the
existing framework, keyboard semantics, and no-bespoke-JavaScript constraint.
No package dependency was added or changed.

No scientific calculation, metric definition, denominator guard, applied
snapshot, or export contract changed.
