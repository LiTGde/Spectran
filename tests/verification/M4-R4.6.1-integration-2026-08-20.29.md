## Scope

This revision addresses `M4-UX-R32` and the user-corrected scope of
`M4-UX-R33`. It changes keyboard interaction and responsive export layout
only. Scientific calculations, metric definitions, catalogue data, and
exports are unchanged.

## Changes

- A delegated Space-key handler restores native checkbox activation where the
  legacy Shiny stack otherwise suppresses it.
- If a reactive update replaces the activated checkbox, focus is restored to
  the replacement control without stealing focus after the user has moved on.
- The handler applies to ordinary Analysis options, Transmission measurement
  qualifications and acknowledgements, Results plot options, and Export
  bundle choices.
- The Export bundle checklist uses an explicit three-column desktop grid.
  Thirteen items therefore form five rows: `3 + 3 + 3 + 3 + 1`.
- The checklist reduces to two columns from 768 through 1023 px and to one
  column below 768 px.
