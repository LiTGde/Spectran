## Addressed findings

- `M2-UX-R01`: Production-facing Apply status no longer exposes draft or
  applied revision counters. Valid stale drafts say, "Results are out of date.
  Apply the current filter again." Invalid stale drafts say, "Results are out
  of date. Resolve the current readiness actions before applying again."
  Invalid drafts keep Apply disabled. Status updates use a polite, atomic live
  region.
- `M2-UX-R02`: Enter and Space now activate the same R Apply function as a
  mouse click. The implementation uses the established `shinyjs::onevent()` R
  API, ignores keyboard auto-repeat, and suppresses a cross-mode duplicate if
  a browser also emits a native click. The ordinary Shiny action button and
  its semantics are retained. A high-contrast focus outline is explicit.
- `M2-UX-R03`: A concise root-cause explanation appears before the first
  metric table. Technical warnings are grouped into retained proportions,
  action factors, and DERs inside a collapsed native details control. The
  underlying metric warnings in the immutable snapshot remain unchanged.

No scientific calculation, weighting, efficacy constant, unit, or metric
definition changed in this revision.

## Browser verification

The isolated app was exercised in the Codex in-app browser with deterministic
local fixtures.

- Initial state: Apply disabled with three readiness actions.
- Enter: applied the ready selective filter and advanced the Apply sequence
  exactly once.
- Space: reapplied a valid stale draft and advanced the sequence exactly once.
- Mouse: applied the zero-source draft and advanced the sequence exactly once.
- Repeated Apply: remained stable and produced a current snapshot.
- Focus: the focused Apply button retained a 3 px blue outline, a 3 px offset,
  and a white separation ring.
- Valid stale draft: showed the required Apply-again message and kept Apply
  enabled.
- Invalid stale draft: showed the required readiness-resolution message, kept
  Apply disabled, retained the prior snapshot at opacity 0.52, and exposed
  `aria-live="polite"` with `aria-atomic="true"`.
- Zero source: showed the concise explanation before the first table. All
  affected cells remained `Undefined`. The technical control was collapsed by
  default and contained 17 messages grouped as 12 retained metrics, 5 action
  factors, and 5 DERs when expanded.
- Browser diagnostics contained no warning or error entries.

Responsive checks used 320, 390, 768, 1024, 1200, and 1440 px widths. The
expanded warning details remained contained at every width, and no width
produced page-level horizontal overflow. Metric tables retained their own
scroll regions.
