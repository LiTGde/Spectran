## Scope

This revision implements the user's collected localization and layout
feedback. It changes presentation, terminology, localized catalogue copy,
and export layout only. Scientific calculations and metric definitions are
unchanged.

## Changes

- The desktop hamburger control is placed within the 150 px sidebar header.
- General English and German interface strings continue to be generated from
  `data-raw/languages.xlsx`.
- Catalogue-specific narrative copy is stored in a separate R preparation
  source and materialized as `_en` and `_de` fields, keeping future catalogue
  localizations accessible without mixing them into the general UI workbook.
- The German Spitschan tail-treatment explanation is localized.
- German `Aktionsfaktor` and `Aktionsfaktoren` are replaced by `Wirkfaktor`
  and `Wirkfaktoren`.
- German preview headings use `Vorschaugrafik`.
- Scientific result fractions use exactly three decimal places in English and
  German. Percentages retain their existing presentation. Raw preview input
  values retain adaptive precision for auditability.
- Export maximum-irradiance and plot-plus-table selectors share a consistently
  aligned secondary settings row.
- The bundle checklist uses the full available desktop width. It forms six
  columns and three rows for the 13 current items, then collapses to one
  contained column on narrow screens.
