## User-directed changes

- Transmission remains an optional page after Export and is no longer the
  automatic import destination.
- The five-tab prototype is replaced by six Analysis-style tabs:
  Transmission spectrum, Details, Normalization, Results, Promotion and
  History, and Export.
- Readiness is shown only on Transmission spectrum and follows that tab's
  content. The module no longer creates its own vertical scroll region.
- Back and forward actions guide users through the input tabs. When no details
  or normalization decisions are needed, the first action applies the filter
  and opens Results directly.
- An attempted Apply with incomplete information opens a modal that groups the
  missing actions by tab and provides direct navigation buttons.
- The normalization preview labels 380 nm and 780 nm explicitly. Complete
  boundary coverage receives a prominent message that no tail decision is
  needed.
- Missing tails can now be completed with 0%, 100%, or the first or last
  supplied value carried to the calculation boundary. Carry decisions receive
  explicit completed-grid status values and audit text.
- Preview details are an unmistakable disclosure labelled Show in English and
  Einblenden in German. Their tables use the Spectran and Analysis typography.
- Results load as one continuous Analysis-style package. All three gt tables
  are prepared on Apply, including tables in inactive metric tabs.
- Current Apply controls disappear after a successful Apply and reappear when
  the result becomes stale. Plot options appear only when a result exists.
- The result plot uses Analysis wavelength breaks, a black dashed transmitted
  curve, optional lighter or unfilled incident spectrum, and optional
  photopic and alpha-opic curves. Panel B is integrated into the same figure,
  narrower at wide viewports and stacked at narrow viewports.
- Plot legends no longer consume a separate export column. Compact labels are
  inside the figure and all plot exports include the Spectran watermark.
- Promotion is more prominent. Frozen promoted results remain available after
  promotion, including plot and table inspection.
- Export is now a dedicated tab with single and bundled figure, table, data,
  history, and audit downloads. Tables are available as PNG and CSV.
- Transmission is visually separated from the core Import, Analysis, and
  Export group in the sidebar.
- English and German wording was updated throughout, including the requested
  concise panel B label without the word narrower.
